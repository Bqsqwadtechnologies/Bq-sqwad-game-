# BQ Sqwad Game

## Landly City

The official game-development repository for the BQ Sqwad universe.

### Vision
Build an original online action-adventure universe centered on Landly City and the BQ Sqwad characters. The project starts as a zero-cost playable prototype and is designed to grow into a production multiplayer game.

### Alpha 0.1
- Landly City prototype environment
- Third-person player controller
- Ziking as the first playable BQ Sqwad character
- BQ Sqwad HQ
- First mission framework
- Basic enemy/combat framework
- Player progression
- Firebase account/progression integration
- Multiplayer-ready architecture

### Technology direction
- Godot for the game client/prototype
- GitHub for source control and project history
- Firebase for authentication and persistent player data
- Dedicated authoritative multiplayer infrastructure when online gameplay begins

### Development principles
1. No fake backend behavior presented as production functionality.
2. Build in small, testable milestones.
3. Keep multiplayer architecture in mind from the beginning.
4. Protect credentials; never commit Firebase private keys or secrets.
5. Preserve the BQ Sqwad/Landly City identity and original intellectual property.
6. Use placeholders during engineering when final art is not yet available.
