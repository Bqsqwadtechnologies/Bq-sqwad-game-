# BQ Sqwad Characters

The character system is data-driven so official character assets can be uploaded and integrated later without rebuilding the gameplay architecture.

## Asset pipeline

Final BQ Sqwad character models, textures, rigs, animations, voices, and reference material will be added as they become available. Temporary engineering assets must remain clearly separated from official production assets.
