# BQ Sqwad — Privacy Notice

**Effective:** September 16, 2026

BQ Sqwad is a game developed by **BQ Sqwad Technologies**.

## Current game build

- The game does not require an account to play the current offline experience.
- Game settings are stored locally on the player's device using Godot's `user://` storage.
- The current settings system stores preferences such as audio volume and display mode locally.
- When a player chooses to host or join an online multiplayer session, the network address and port entered by the player are used to establish that session.
- The current game does not intentionally collect a player's name, email address, contacts, photos, microphone recordings, or advertising profile for the offline experience.

## Online features

The multiplayer foundation uses a direct network session. Future online services may introduce additional account, matchmaking, moderation, or telemetry systems. This notice will be updated before those services are enabled in a public release.

## Children and families

The current game is designed to avoid requiring personal information for ordinary offline play. Players should not enter another person's private information into game fields.

## Changes

If the game's data practices change, this notice will be updated and the release documentation will identify the relevant changes.
