# BQ Sqwad Audio Pack

The game audio system is ready for a layered Landly City soundscape.

## Music
Place area music in `assets/audio/music/` using names containing:

- `opening` or `theme` — opening music
- `downtown` — central city
- `college` — Landly College
- `training` — training district
- `mission` — mission district
- `military` — defence/military district
- `hq` — BQ Sqwad HQ

Supported formats: `.ogg`, `.wav`, `.mp3`.

## Area / world sounds
Place sounds in `assets/audio/sfx/` using names containing:

- `traffic` / `car` — passing traffic
- `college_ambient` — college ambience
- `square_ambient` — public square ambience
- `military_ambient` — military-zone ambience
- `hq_ambient` — HQ ambience
- `crowd` / `city` / `horn` — occasional city sounds

The game positions world sounds in 3D, so they become quieter with distance and are spatially heard around the player. The settings menu provides separate **Music Volume**, **Area Sounds / Ambience**, and **Master Volume** controls.

Do not add copyrighted audio without the necessary rights. Final game music and sound assets should be original, licensed, or otherwise cleared for use by BQ Sqwad Technologies.
