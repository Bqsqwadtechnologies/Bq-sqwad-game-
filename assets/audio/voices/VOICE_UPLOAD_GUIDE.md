# BQ Sqwad character voices

Add one voice file per character when ready:

- `ziking/voice.ogg`
- `goodshina/voice.ogg`
- `star/voice.ogg`
- `ella/voice.ogg`
- `ep/voice.ogg`

You may leave the original uploaded filename if you prefer; the game metadata points to `voice.ogg` as the normalized runtime path.

## Dialogue modes

- **Character Voice:** plays the supplied character voice asset.
- **Speak for Character:** uses the player's microphone for that character's dialogue.

Microphone input should be permission-gated by Android and can be enabled/disabled from the in-game voice control. No microphone recording should be uploaded to a server by this game layer.
