# BQ Sqwad Game Assets

This is the controlled asset area for BQ Sqwad Game.

## Important

Place original BQ Sqwad assets and approved references here. Keep source references separate from generated concepts and final game-ready assets.

See `docs/ASSET_PIPELINE.md` for the complete workflow.

## Main categories

- `characters/` — BQ Sqwad character references and production assets
- `world/landly_city/` — city, buildings, roads, vehicles, landmarks and environment references
- `audio/` — music, sound effects and approved voice assets
- `cinematics/` — cinematic references and production material
- `ui/` — interface artwork
- `logos/` — BQ Sqwad and game branding
- `temporary/` — short-term working material only
